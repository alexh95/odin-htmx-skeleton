# Changelog

All notable changes to this project are recorded here. Format follows
[Keep a Changelog](https://keepachangelog.com/). **Every behaviour/structure/build change gets an
entry under `[Unreleased]`** — see `CLAUDE.md`. Entries track
[Conventional Commits](https://www.conventionalcommits.org): `feat`→Added, `fix`→Fixed,
`refactor`/`perf`/`style`→Changed, removals→Removed.
